# day-planner-idea
Идея ИИ-планировщика дня для студентов и пенсионеров: расписание, питание, тренировки, напоминания.
## Цель  
Помочь людям не теряться между задачами, не забывать есть, высыпаться и заботиться о себе — без переключения между 5 приложениями.  


## Для кого  
- Студенты — баланс пар, дедлайнов и сна.  
- Пенсионеры — контроль таблеток, прогулок, щадящая нагрузка.  
- Офисные сотрудники — фокус-слоты, перерывы, питание без фастфуда.  
- Фрилансеры — тайм-блоки под проекты, борьба с прокрастинацией.  


## Как это работает  
1. Анкета: возраст, график, цели, ограничения (здоровье, бюджет).  
2. ИИ генерирует план дня с тайм-слотами и адаптацией под изменения.  
3. Интеграция: календарь, трекер привычек, фото холодильника → меню.  
4. Напоминания + мягкая корректировка плана в течение дня.  
 

## MVP (Telegram‑бот)  
- Бесплатная пробная версия (3 дня).  
- Подписка: 199 ₽/неделя или 599 ₽/месяц.
