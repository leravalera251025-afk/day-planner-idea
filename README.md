# day-planner-idea
Идея ИИ-планировщика дня для студентов и пенсионеров: расписание, питание, тренировки, напоминания.
## Цель  
Помочь людям не теряться между задачами, не забывать есть, высыпаться и заботиться о себе — без переключения между 5 приложениями.  

## Как это работает  
1. Пользователь заполняет анкету: возраст, рост, вес, цель (похудеть, набрать, поддерживать), заболевания, бюджет.  
2. Бот предлагает план дня с тайм‑слотами.  
3. Можно прикрепить фото холодильника — бот предложит меню из доступных продуктов.  
4. Каждый день — напоминания, корректировка плана, поддержка.  

## Для кого  
- **Студенты** — не хватает времени, денег, сил.  
- **Пенсионеры** — важно не забыть таблетки, выйти на прогулку, не перегружаться.  

## MVP (Telegram‑бот)  
- Бесплатная пробная версия (3 дня).  
- Подписка: 199 ₽/неделя или 599 ₽/месяц.  
- Партнёрки: рекомендации продуктов, фитнеса, хобби.
